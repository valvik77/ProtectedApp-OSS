INSTALACIÓN INFORMADA

Comprueba antes de instalar.

Las builds actuales usan un certificado de desarrollo público. La firma y el hash identifican el archivo; no eliminan las advertencias de confianza de Windows.

  1. 01

    Descarga solo desde GitHub Releases

    Obtén instalador, .sha256, SBOM y certificado público de la misma release.

  2. 02

    Verifica el hash

    Get-FileHash .\ProtectedApp-Setup-x64-*.exe -Algorithm SHA256

  3. 03

    Comprueba la firma

    Get-AuthenticodeSignature .\ProtectedApp-Setup-x64-*.exe | Format-List

  4. 04

    Decide si confías en el certificado

    Solo para el usuario actual de un equipo de pruebas; nunca en LocalMachine.

warning

Smart App Control, WDAC y políticas corporativas pueden bloquear estas builds. No desactives defensas para evitar avisos.
