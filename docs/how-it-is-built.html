CÓMO SE CONSTRUYÓ

Una herramienta local,
no una caja negra.

ProtectedApp se desarrolla como una aplicación de escritorio WinUI 3 para Windows. El código, scripts de compilación y documentación de seguridad están disponibles para revisión.

ARQUITECTURA

desktop_windows

Panel WinUI 3

Configura reglas, bóvedas, copias, horarios y diagnósticos. Puede permanecer oculto en el área de notificación.

→
shield

Guardian

Servicio de Windows independiente que aplica las reglas de aplicaciones protegidas aunque el panel no esté abierto.

→
folder_lock

Motor de bóvedas

Contenedores cifrados, unidades virtuales Dokany, journals autenticados y recuperación tras una interrupción.

DECISIONES DE DISEÑO

Local primero.

No hay cuentas, sincronización de secretos ni telemetría integrada. Las bóvedas son archivos .pavault que puedes almacenar y copiar bajo tu propio control. Las alertas remotas solo existen si se configura expresamente un webhook.

Revisar el modelo de seguridad →
  • Cifrado autenticadoAES-256-GCM para contenedores y journals
  • Recuperación con prioridadCommit atómico, journal y copia cifrada anterior
  • TPM optativoSegunda clave ligada al equipo, con copia portátil previa

PARTICIPA

El proyecto mejora con revisión crítica.

Buscamos comentarios sobre modelo de amenazas, instalación, compatibilidad de Windows y recuperación de bóvedas. No publiques secretos ni detalles explotables: los informes de seguridad tienen un canal privado.
