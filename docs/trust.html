SEGURIDAD Y CONFIANZA

Protección local,
límites claros.

ProtectedApp explica qué protege, qué cambia en Windows y qué no puede prometer. Decide con información antes de instalarlo o usarlo con datos importantes.

visibility_off

Sin telemetría

La aplicación no incorpora analítica ni envía archivos, contraseñas, rutas o contenido de bóvedas. El webhook de alertas es opcional y se configura expresamente.

encrypted

Bóvedas autenticadas

Los contenedores .pavault usan AES-256-GCM y PBKDF2-SHA256. Las ediciones se recuperan mediante journals cifrados y el contenedor solo se reemplaza tras una consolidación verificada.

rule

No es una frontera absoluta

No sustituye BitLocker, Secure Boot, cuentas de Windows, copias de seguridad ni WDAC. No protege frente a un administrador local, SYSTEM, malware privilegiado o una sesión desbloqueada.

memory

TPM opcional

El TPM añade una clave no exportable del equipo. No sustituye la contraseña ni las copias; un reinicio del TPM, una reinstalación de Windows o un cambio de placa puede impedir el acceso a elementos vinculados.

INTEGRIDAD DE VERSIONES

Comprueba antes de confiar.

  1. 01

    Fuente oficial

    Descarga únicamente desde GitHub Releases y revisa el commit y las notas de la versión.

  2. 02

    Hash y firma

    Compara el SHA-256 del instalador y valida la identidad de la firma antes de ejecutarlo.

  3. 03

    Certificado actual

    Las builds publicadas usan un certificado de desarrollo documentado, no una identidad comercial de confianza pública. Windows puede advertir o bloquearlas.
