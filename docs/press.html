Descripción corta

ProtectedApp es una aplicación open source para Windows que protege aplicaciones de escritorio con contraseña y permite crear bóvedas locales cifradas para archivos sensibles.

Descripción larga

ProtectedApp combina protección de aplicaciones, bóvedas .pavault con cifrado autenticado, bloqueo automático, recuperación cifrada y un servicio Guardian independiente. El proyecto es local-first: no necesita cuenta y no incorpora telemetría. Documenta de forma explícita sus límites y el estado de confianza de sus builds.
